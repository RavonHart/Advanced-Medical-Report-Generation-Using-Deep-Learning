# 🏥 Medical Report Generation from Chest X-rays

An end-to-end deep learning pipeline that generates structured radiology reports from chest X-ray images using CNN + Attention + LLM refinement.

---

## 🚀 Features

- DenseNet-based image encoder
- Attention-based LSTM decoder
- Multi-label disease classification
- LLM refinement using Gemini API
- Automatic PDF report generation

---

## 🧠 Architecture

Image → CNN Encoder → Attention Decoder → Text Report → LLM Refinement → PDF

---

## 📊 Results

| Metric | Score |
|--------|------|
| BLEU-1 | 0.37 |
| BLEU-4 | 0.14 |
| Clinical F1 | 0.40 |
